# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入多只行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过各箱俯视图、侧视图、重量/空间指标、总清单和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 多箱联合规划：行李箱数量、长宽高与承重配置
- 每件物品可指定箱子，或交给系统在各箱尺寸/承重范围内自动分配
- 必带物品优先装入，再安排可选物品；三套策略各自给出分箱图与总清单
- 重新分配只移动未指定箱子的物品，不会覆盖用户指定
- 某箱放不下时保留其他箱子的有效结果，并逐件列出未分配原因，不重复计重
- 删除有物品的箱子前预览重新分配结果，确认后一次保存并持久化
- 确定性三维长方体装箱、旋转与碰撞检测
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存（含旧版单箱数据迁移）与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。多箱联合规划先装用户指定箱子的物品（放不下则保留指定并记录原因），再把未指定的物品按“必带 → 优先级”顺序分配到剩余空间最小的可用箱子；每件物品只装箱一次。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

## 开发与测试

```bash
npm install
npm run dev
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

## Docker

```bash
docker compose up --build
```
