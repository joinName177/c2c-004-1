# c2c-004 · 行李箱空间规划师

Vue 3 + TypeScript + Vite 纯前端行李打包工具。录入多个行李箱和物品后，可比较“精简版、舒适版、购物版”三种装箱策略，通过分箱图、俯视图、侧视图、重量/空间指标、整趟行程总清单和风险清单理解摆放结果，并打印装箱清单。

## 功能

- 多行李箱管理：分别配置长宽高与承重，可随时增删
- 多箱联合规划：每件物品可指定箱子或交给系统分配，各箱在尺寸与承重范围内优先满足必带物品，再安排可选物品
- 物品清单、类别、尺寸、重量、优先级、必带标记和指定箱子
- 确定性三维长方体装箱、旋转与碰撞检测；每件物品只装入一个箱子，不重复计重
- 三套策略的分箱图、双投影视图联动和整趟行程总清单（含未分配原因）
- 重新分配只移动未指定箱子的物品，不改动用户指定；某箱放不下时保留其他箱子的有效结果
- 删除有物品的箱子前预览重新分配结果，确认后一次保存箱子、物品归属和方案
- 超重、空间紧张、尺寸越界、必需品遗漏、易碎品受压和重心风险
- localStorage 本地保存（含已计算的方案，刷新后保持同一份安排）与打印清单

## 分层架构

- `src/core`：领域模型、几何、装箱算法、策略编排与风险规则
- `src/ports`：规划仓储与打印接口
- `src/adapters`：localStorage 与浏览器打印实现
- `src/ui`：Vue 控制器、组件与原生 CSS

依赖只由 UI/适配器指向端口和核心层；核心层不读取浏览器状态，可独立测试。

## 装箱算法

引擎为每件物品枚举唯一的轴向旋转，并按“低层 → 靠后 → 靠左”的候选角点尝试放置。每次放置都检查箱体边界、长方体相交、方案承重和预留体积。多箱联合规划先满足用户指定箱子的物品（指定物品放不进时保留原因、绝不挪箱），再把未指定物品按“必带优先”顺序分配到剩余空间最紧的可用箱子。它是快速、可解释的启发式算法，不保证数学意义上的全局最优，也不模拟软质物品压缩。

```bash
npm test
npm run build
```

数据只保存在当前浏览器的 `localStorage`，不会上传。

```bash
docker compose up --build
```
